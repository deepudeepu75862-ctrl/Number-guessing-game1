# Task 1: Number Guessing Game

**Internship:** Cognifyz Technologies — Software Development  
**Level:** Beginner  
**Language:** Python

## Description
A simple text-based game where the computer randomly chooses a number from 1 to 10. The player guesses the number and receives hints telling them whether their guess is too high or too low.

## Features
- Random number generation
- `if` / `elif` / `else` conditional statements
- Repeated guesses using a `while` loop
- Input validation
- Attempt counter
- Option to play again or quit

## Requirements
- Python 3.8 or later
- No external libraries required

## How to Run
1. Download and extract this ZIP file.
2. Open a terminal or command prompt in the extracted folder.
3. Run:

   ```bash
   python task1_number_guessing_game.py
   ```

   On some systems, use `python3` instead of `python`.

## Example
```text
=== Number Guessing Game ===
I'm thinking of a number between 1 and 10.
Enter your guess (or q to quit): 4
Too low! Try again.
Enter your guess (or q to quit): 7
Correct! You guessed the number in 2 attempt(s).
```

Variables, input/output, random numbers, loops, conditionals, exception handling, and functions.
